## 📖 About

This repository documents my **100 Days of Code** journey, where I commit to solving DSA problems daily — building consistency, sharpening problem-solving skills, and preparing for technical interviews.

Each day's folder contains the source code for problems I solved that day — ranging from foundational concepts in **C** to advanced data structure problems in **Java**.

## 💡 Key Takeaways (So Far)

- **Consistency beats intensity.** Showing up every day matters more than solving the hardest problem.
- **Struggle is part of learning.** The problems that took hours taught me the most.
- **Fundamentals are everything.** Strong basics in arrays, strings, and linked lists make advanced topics far more approachable.
- **Track your progress.** Looking back at Day 1 vs Day 50 shows how much growth is possible with daily practice.
